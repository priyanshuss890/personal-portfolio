## 📄 What this is

Everything (markup, styles, behavior) lives in a single ~27 KB document, so the whole site deploys anywhere a static file can go.

## 🎨 Design

> **"Technical editorial"** — warm paper against true ink, with a single vermilion spot color. 🔴

| | |
|:--|:--|
| ✍️ **Type** | Instrument Serif (display) · Figtree (body) · JetBrains Mono (labels & metadata) |
| 🌗 **Theme** | Follows the OS via `prefers-color-scheme`, plus a manual nav toggle that persists to `localStorage` |
| 🎞️ **Motion** | `IntersectionObserver` scroll reveals · animated number tickers · scramble-in kicker · drifting aurora blobs · rotating SVG stamp |
| ♿ **Accessibility** | Every animation switches off under `prefers-reduced-motion: reduce` |
| 📱 **Responsive** | Fluid `clamp()` type scales · grids collapse to single-column on small screens |

## ▶️ Running it

Open `index.html` in any browser. That's genuinely it. 🎉

Prefer a local server?

```bash
python -m http.server 8000
# → http://localhost:8000
```

## 🚢 Deploying

Works on any static host — **GitHub Pages**, **Netlify**, **Vercel**, **Cloudflare Pages**. One file, nothing to build.

<details>
<summary>📘 <b>GitHub Pages in three clicks</b></summary>

<br>

1. **Settings** → **Pages**
2. **Source** → *Deploy from a branch*
3. Branch → **`main`** / **`/ (root)`** → **Save**

Live shortly at `https://priyanshuss890.github.io/personal-portfolio` 🌐

</details>

## 🧰 Editing

Everything is in `index.html`:

| Change | Where |
|:--|:--|
| 🎨 Colors | CSS custom properties under `:root` (and the two dark-mode blocks below it) |
| ✏️ Copy | The markup in `<body>` — each section is a plain `<section>` with a matching `id` |
| 🔢 Hero counters | The `data-n` / `data-suf` attributes on `.ledger b` |
| ⚡ Behavior | The single `<script>` block at the bottom |
